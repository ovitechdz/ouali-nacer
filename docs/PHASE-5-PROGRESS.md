### Why the remaining mass is hard

Temporary split build (manualChunks, config deleted afterwards) gave the eager composition:

| Group | gzip | Notes |
| --- | --- | --- |
| react + react-dom | 66.3 kB | floor for a React app |
| misc vendor (idb, ulid, clsx, tailwind-merge, …) | 37.9 kB | idb is boot-critical (repository) |
| zod | 25.6 kB | parsing the stored document at boot |
| app entry code | 23.8 kB | shell, gate, storage recovery |
| @tanstack/react-router | 26.3 kB | routing |
| i18next core | 15.6 kB | translations before first paint |
| lucide icons | 6.1 kB | shell/gate icons only |

The 150 kB target requires deferring boot-critical services (repository + zod parsing) behind the
FarmGate loading state — a behavioural refactor, not an import move.
